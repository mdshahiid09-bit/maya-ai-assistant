# Maya AI Assistant (Free & Unlimited) 🎙️📱

**Maya Assistant** is an open-source, Jarvis-inspired personal voice assistant for Android. It connects directly to Google Gemini 1.5 and ElevenLabs, giving you full conversational AI and real phone automation with zero subscription fees, zero timers, and 100% privacy.

---

## 🌟 Key Features

* **⚡ Google Gemini 1.5 Intelligence:**
  - Unlimited usage with your own free Google Gemini API Key.
  - Native function calling for direct phone execution.
* **🗣️ Human-like ElevenLabs Voices:**
  - High-fidelity voice responses using ElevenLabs TTS.
  - Smart fallback to Android Native Text-to-Speech when offline or out of quota.
* **📱 Real Phone Control (Accessibility & Intents):**
  - Open installed apps (WhatsApp, YouTube, Settings, etc.).
  - Dial calls & compose WhatsApp messages hands-free.
  - Set alarms and timers.
  - Hardware controls: Volume up/down, Home, Back, Notifications.
  - Screen automation: Click visible buttons/text by name.
* **🔒 100% Private & Open Source:**
  - No middleman backend servers.
  - Your API keys are encrypted locally on your phone.
* **🚀 Automatic APK Compilation (GitHub Actions):**
  - Every commit automatically compiles a fresh Android `.apk` via GitHub Actions!

## 📥 How to Download the APK

1. Go to the [Releases](https://github.com/mdshahiid09-bit/maya-ai-assistant/releases) section or the [Actions Tab](https://github.com/mdshahiid09-bit/maya-ai-assistant/actions).
2. Download `app-debug.apk`.
3. Install the APK on your Android device.

---

## ⚙️ Quick Setup

1. Open **Maya Assistant** on your phone.
2. Tap the **Settings (⚙️)** icon in the top right.
3. Paste your **Google Gemini API Key** ([Get free key here](https://aistudio.google.com/)).
4. (Optional) Paste your **ElevenLabs API Key** and custom Voice ID.
5. Tap **Save & Apply**.
6. When prompted, enable the **Maya Accessibility Service** in Android Settings to unlock hands-free phone control.
